# Healthcare Management System – SQL Project

## Description
This project is a MySQL-based Healthcare Management System database.
It manages patients, doctors, appointments, encounters, diagnosis,
procedures, prescriptions, tests, and billing.

## Database Used
- MySQL

## Major Tables
- patient
- doctor
- department
- appointment
- encounter
- diagnosis
- disease
- prescription
- billing

## Features
- Patient and doctor management
- Appointment and encounter tracking
- Diagnosis and disease mapping
- Prescription and medication records
- Procedure and billing management

## Files Included
- healthcare_management.sql – complete database structure and data
- queries.sql – important SQL queries for analysis

## Purpose
Created to practice advanced SQL concepts such as joins,
foreign keys, normalization, and real-world database design.
